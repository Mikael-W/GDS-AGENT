# Kanban

Un fichier par épic, déplacé de colonne en colonne : `backlog/` (à faire), `inprogress/` (en cours, peu à la fois), `done/` (livré en production). Nouveau fichier : copier `TEMPLATE.md` en `backlog/EPIC_<NN>_<NOM>.md`.

Une épic est finie quand ses critères d'acceptation sont vérifiés en production, pas quand le code est écrit.
